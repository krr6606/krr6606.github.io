# /portfolio-intake 출력 형식

재료집·촬영목록은 아래 형식을 그대로 씁니다. `<…>`만 채우고, 해당 내용이 없으면 그 행을 지우지 말고 "없음(근거)"이나 ❓로 둡니다.
**서술문은 안내 문구(이 파일에 있는 문장)만** 씁니다. 기능을 설명하는 문장은 쓰지 않습니다.

## `_intake/재료집.md`

바깥 펜스(````)는 이 설명 파일의 표시용입니다. 재료집에는 그 안쪽만 씁니다.

````markdown
# <productName 또는 레포 이름> — 재료집 · 질문지

> ⚠ 이 파일은 **프로젝트 문서가 아닙니다.** 코드와 커밋 기록에서 확인한 사실과, 여러분만 답할 수 있는 질문입니다.
> 질문에 답하면서 `../프로젝트문서.md`를 **직접** 새로 쓰세요. 이 파일을 그대로 옮기거나 이름만 바꾸면 안 됩니다.
> 아래 절 이름(시스템 구조·핵심 기능·고민과 선택 등)은 **질문을 묶은 틀**입니다. 프로젝트 문서의 제목·소제목으로 그대로 쓰지 말고 **내용의 이름**으로 지으세요
> (예: "3.2 핵심 기능" ✗ → "3.2 제작 한 번의 흐름" ○). 코드 이야기든 게임 디자인 이야기든 답할 수 있는 질문에 답하면 됩니다. "(선택)" 절은 해당할 때만 씁니다.
> 답한 질문은 `- [ ]`를 `- [x]`로 바꿔 두세요. `/portfolio-check`가 남은 질문을 세어 무엇이 더 필요한지 알려 줍니다(재료 점검표).
> 코드에 없는 내용(고민과 선택·AI 협업·회고·플레이 화면)은 다른 자료가 필요합니다. 기획서·회의록·AI 대화 기록·플레이테스트 메모가 있으면 이 폴더 안 `자료/`에 넣어 두세요(`format/07-materials.md`).
> 이 폴더(`_intake/`)는 git에 올라가지 않습니다. 프로젝트 문서를 다 쓰면 지워도 됩니다.
> 출처: <url> @ <SHA 7자리> (받은 날 <YYYY-MM-DD>) · 자세한 점검: `report-intake.md`

| 표시 | 뜻 |
|---|---|
| ✅ 사실 | 코드·설정·커밋에서 확인. 괄호 안이 근거(`경로:줄` / 커밋 해시) |
| ❓ 질문 | 여러분만 답할 수 있음. 답이 프로젝트 문서의 본문이 됩니다 |
| ⚠ 추정 | Claude의 해석. 맞는지 확인하고, 틀리면 버리세요 |
````

1. 머리 — "프로젝트 문서가 아님" 안내, 출처(파일 SHA-256 앞 12자리·슬라이드 수·파일 속성의 마지막 수정일 — **파일 이름·작성자는 쓰지 않음**), 표시(✅ 원문 · ❓ 질문 · ⚠ 확인)
2. `## 한눈에` — 슬라이드(숨긴 장)·제목을 짐작한 장·그림(웹에서 안 보이는 형식)·표·차트·SmartArt·노트·링크·영상·파일 날짜·가린 글 개수
3. `## 슬라이드` — `### <번호>. <제목>`마다 글(단락 = `- `, 수준마다 두 칸 들여쓰기) · 표 · 차트 값 표 · SmartArt · 그림(`pptx/…` 크기·형식·대체 텍스트·⚠) · 영상 · 발표자 노트(`> `). 구역이 바뀌면 `**〔구역: …〕**`
4. `## 그림 목록` — 고르는 법(4~6장 · `cover.png` · 남의 그림 금지 · 다이어그램은 mermaid로 · 용량 제안값)과 표(파일·슬라이드·크기·용량·형식·비고)
5. `## 링크` · `## 파일로 들어 있는 영상·소리`(있을 때만)
6. `## 질문 — 프로젝트 문서 5단 구조` — 재료집 §0~§5와 같은 번호의 ❓ 질문(레포 재료가 없으면 `/portfolio-intake <레포>` 안내)
7. `## 옮기지 않은 것`

그림 파일 이름: `s<슬라이드 번호(두 자리 이상)>-<그 장에서 n번째>.<형식>`, 배경은 `s<번호>-bg.<형식>`. 같은 그림은 처음 나온 장의 이름으로 한 번만. 다시 꺼낼 때(`--replace`) 이 이름 규칙의 파일만 지우고 새로 씁니다.

## `_intake/intake.json`

```json
{
  "source": "https://github.com/<o>/<r>",
  "sha": "<40자>",
  "fetchedAt": "<YYYY-MM-DD>",
  "root": "<루트 접두어, 없으면 \"\">",
  "githubId": "<profile.md의 아이디 또는 \"\">",
  "files": [{ "code": "code/<파일>.cs", "from": "<원래 경로>" }],
  "pptx": { "sha256": "<64자>", "slides": 0, "extractedAt": "<YYYY-MM-DD>", "md": "발표자료.md", "images": ["s01-1.png"] }
}
```

이메일·남의 이름은 넣지 않습니다. `pptx`는 §9의 스크립트가 쓰고(발표 자료 파일 이름은 넣지 않음), 레포 항목(`source`~`files`)은 §7이 씁니다 — 서로의 항목을 지우지 않습니다. 발표 자료만 꺼낸 폴더에는 `pptx`만 있습니다.
