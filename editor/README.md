# 웹에서 바로 고치기 (editor/)

내 컴퓨터에서 포트폴리오 문서·발표 덱·상세 기술문서를 **보면서 바로 고치는** 도구입니다.
렌더러(`index.html`·`project.html`·`doc.html`·`assets/`)는 건드리지 않고, 편집 서버로 열었을 때만 페이지에 편집 도구가 끼워집니다.
GitHub Pages에 올라간 페이지에는 편집 도구가 나오지 않습니다.

## 켜기

레포 폴더에서 (Windows에서 `python`이 없으면 `py`):

```bash
python editor/server.py
```

→ <http://localhost:4601> 을 엽니다. Claude 데스크톱 앱에서는 `.claude/launch.json`의 `portfolio-edit` 구성으로 켤 수 있습니다.
평소 미리보기(`python -m http.server 4600`)는 그대로 쓸 수 있고, 그쪽에는 편집 도구가 없습니다.

## 무엇을 어디서 고치나

| 화면 | 하는 법 | 저장되는 곳 |
|---|---|---|
| 상세 기술문서 | 오른쪽 **[✎ 문서 고치기]** → 왼쪽 원문 / 오른쪽 미리보기. 미리보기의 글·표·코드를 누르면 원문의 그 줄로 감. 고치면 미리보기가 바로 바뀜. `Ctrl+S` 저장. 그림은 붙여 넣기(`Ctrl+V`)·끌어다 놓기·[그림] 단추 | `src/<폴더>/<기술 문서>.md`, 그림은 `src/<폴더>/images/` |
| 포트폴리오 문서 | **[✎ 편집] → 내 정보**: 이름·정체성·자기소개·연락처·강조색·프로젝트 순서 | `profile.md` (+ `data/portfolio.json`의 같은 칸) |
| 발표 덱 | **[✎ 편집] → 장면**: 지금 보는 장면의 틀·제목·도입·요점·그림/코드/표 고르기·코드 줄 범위·순서·숨기기·되돌리기 | `src/<폴더>/deck-edits.json` → `deck-edits.py apply` (`/portfolio-edit`와 같은 파일) |
| 세 페이지 공통 | **문구** 탭: 절 이름·버튼·라벨 문구 / **테마** 탭: 색·모양 값 / **바뀐 파일** 탭: 마지막 커밋 뒤 바뀐 파일 보기·되돌리기 | `theme/strings.tsv`의 "내 문구" 칸 / `theme/theme.css` |

- **[화면에서 글 고르기]**: 페이지의 글을 누르면 그 글을 어느 탭(또는 기술 문서)에서 고치는지 찾아 줍니다.
- 포트폴리오 문서의 프로젝트 소개·기능 설명·기술 스택, 발표 덱 장면의 기본 글은 **기술 문서에서 뽑은 요약**입니다.
  기술 문서를 고친 뒤 Claude Code에서 `/portfolio-build`를 다시 실행하면 바뀝니다.
- 발표 덱 장면에 직접 쓴 글은 "직접 고친 글"(`verbatim: false`)로 저장되어 점검 리포트의 "확인해 주세요"에 나옵니다. 사실·설명은 기술 문서에도 적어 두세요.
- 커밋·푸시는 하지 않습니다. 평소처럼 git에서 합니다.

## 안전장치

- `127.0.0.1`(내 컴퓨터)에서만 열리고, 다른 사이트가 보낸 저장 요청은 받지 않습니다.
- 고칠 수 있는 파일이 정해져 있습니다(위 표의 "저장되는 곳"). 렌더러·스킬·`format/`은 쓰지 못합니다.
- 파일의 인코딩·줄 끝(CRLF/LF)·BOM은 그대로 둡니다. 다른 편집기에서 같은 파일을 고쳤으면 덮어쓰기 전에 묻습니다.
- 장면 고치기가 규칙에 맞지 않으면(예: "화면 2~3열" 틀에 그림이 1개) 반영하지 않고 이유를 보여 준 뒤 파일을 원래대로 둡니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `server.py` | 편집 서버(Python 3.8 이상, 표준 라이브러리만) |
| `edit.js` · `edit.css` | 세 페이지에 끼워지는 편집 창 |
| `doc-edit.html` · `doc-edit.js` | 기술 문서 편집 화면 |

이 폴더는 `/portfolio-update`가 건드리지 않습니다(템플릿에 없는 내 파일).
